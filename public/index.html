How to read these numbers

Open-Meteo supplies regional CAMS model estimates. Local monitoring stations can report different conditions. Hourly values and historical charts use the selected city’s time zone.

The US index uses the provider’s US AQI. ClearDay estimates India’s index from eligible rolling pollutant averages. The largest available sub-index determines the category. A missing pollutant can affect the result.
